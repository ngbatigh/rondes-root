## Synthèse : Gestion des compteurs

### 2. Champs de chaque compteur

- `id_compteur` (identifiant unique, format A/B/C-XXXX-XXXX-XXXX-XXXX)
- `nom_compteur`
- `unite_compteur`
- `debut_compteur` (valeur initiale)
- `range_compteur` (plage de valeurs)
- `section_compteur` (liste déroulante depuis constante `sections`)
- `famille_compteur` (liste déroulante depuis constante `familles`)
- `groupe1_compteur` (liste déroulante depuis constante `groupe1`)
- `groupe2_compteur` (liste déroulante depuis constante `groupe2`)
- `enservice_compteur` (date de mise en service, vide si inactif)
- `visible_compteur` (booléen)
- `actif_compteur` (booléen)
- `description_compteur`

### 3. Constantes (listes déroulantes)

const sections = [

### 4. Interface utilisateur (4 sous-menus)

**Menu latéral → 🔢 Gestion des compteurs**

1. **✅ Activer compteur** — Liste de tous les compteurs avec :
   - Badge de statut (✅ Actif & visible / 👁️ Actif mais invisible / ⏸️ Inactif)
   - Cases à cocher 👁️ Visible et ✅ Actif
   - Bouton 💾 Enregistrer les modifications

2. **✏️ Modifier compteur** — Formulaire avec :
   - Liste déroulante pour sélectionner un compteur
   - Champs : ID (lecture seule), nom, unité, début, range, section, famille, groupe1, groupe2, description
   - Listes déroulantes pour section, famille, groupe1, groupe2
   - Cases à cocher visible et actif
   - Boutons 💾 Enregistrer et ❌ Annuler

3. **📋 Cloner compteur** — Formulaire avec :
   - Liste déroulante pour sélectionner le compteur parent
   - Champ texte pour le nouvel ID
   - Aperçu JSON du clone
   - Boutons 📋 Cloner et ❌ Annuler
   - Le clone hérite de toutes les valeurs sauf id_compteur

4. **➕ Créer compteur** — Formulaire complet avec :
   - Tous les champs (id, nom, unité, début, range, section, famille, groupe1, groupe2, description)
   - Listes déroulantes pour section, famille, groupe1, groupe2
   - Cases à cocher visible (✅) et actif (✅) cochées par défaut
   - Boutons ✅ Créer et ❌ Annuler

### 5. Stockage localStorage

| Clé | Contenu |
|-----|---------|
| `sections` | Tableau des 9 sections |
| `famille_list` | Tableau des 7 familles |
| `groupe1_list` | Tableau des 9 groupes 1 |
| `groupe2_list` | Tableau des 9 groupes 2 |
| `tabCompteurs` | Tableau des 9 compteurs |
| `rondeDB` | Objet des relevés par compteur |

### 6. Fonctions JavaScript principales

- `initDatabase()` — Initialise toutes les données au premier lancement
- `loadSavedData()` — Charge depuis localStorage ou appelle initDatabase()
- `fillCompteurSelect()` — Remplit le select des compteurs (filtre visible + actif)
- `renderActiverCheckList()` — Affiche la liste avec checkboxes
- `enregistrerActiver()` — Enregistre les modifications de visibilité/activité
- `remplirSelectModifier()` / `chargerCompteurDansFormModifier()` / `enregistrerModification()`
- `remplirSelectCloner()` / `afficherApercuClone()` / `executerClonage()`
- `creerCompteur()`
- `setupGestionCompteurs()` — Configure tous les événements
